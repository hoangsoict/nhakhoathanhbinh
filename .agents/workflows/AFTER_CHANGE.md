# Workflow: After Change

1. Review `git diff` for modified files.
2. Run relevant lint/build/test when feasible.
3. Update `.agents/memory/SESSION_STATE.md`.
4. Update `.agents/memory/CHANGELOG_AI.md`.
5. Update `.agents/memory/DECISIONS.md` when decisions change.
6. Update `.agents/memory/OPEN_QUESTIONS.md` when questions remain.
7. Final reply: changed files, validation commands, residual risks.
